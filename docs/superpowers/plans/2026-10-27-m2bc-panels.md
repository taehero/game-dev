# M2bc-panels: Screens for People, Money and After-Launch Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After this plan a real player can use, on screen, everything that M2b and M2c built as logic:
- see a **Game Over** screen when the studio goes bankrupt, then start a new game or load the autosave;
- borrow from the bank or the loan shark, repay, see loans, missed payments and monthly costs, and take contract work;
- hire from the monthly candidates, fire with severance shown, and answer raise and promotion asks;
- buy, lease, sell and seat computers, move office, and sign engine licences;
- spend owner skill points and set the owner focus;
- run marketing, start sales promotions, enter the yearly award, and on a live game start a patch, mod tools or a DLC and answer the forum.

**Cut from this plan, said up front:**
- outsourcing (`SignOutsourceCommand`);
- per-staff choice for live tasks (the UI always sends "every free worker");
- a save/load menu (Load means the autosave only);
- the publisher pitch (M2d Ruling P2, still unowned);
- `StateQueries.staff_pose` showing patch staff as IDLE (an office-scene issue, not a panel).

**Architecture:**
- **No new simulation.** The plan adds one small core change, in `GameRunner`: `has_save()`, and no autosave after game over. It also adds read-only `StateQueries` views. Everything else is UI.
- **Sections, not bigger panels.** Each new block of a dock panel is a `PanelSection` (a `VBoxContainer`) in `src/ui/panels/sections/`, with its own file and its own test. `PanelBase.add_section()` mounts it under the panel's body. Only `Main` (Task 28) mounts sections, so parallel tasks never share a panel file.
- **Popups** follow the M2d pattern (`static func popup(...) -> PopupCard`, mounted through `PopupQueue`). `PopupDirector` gains Game Over (Task 10) and raise asks, live-game and forum popups (Task 27).
- The UI reads only through `StateQueries`, gates buttons with the command's own `validate`, and submits through `GameRunner.submit()` (M2d Ruling P14).

**Tech Stack:** Godot 4.7.2, GDScript (static typing), GUT 9.x.

**Spec:**
- `docs/superpowers/specs/2026-10-24-m2-playable-garage-design.md`: §7 (people and money), §8 (after launch, Rulings C3–C18), §9, §10, §11.3 (tabs).
- `docs/superpowers/specs/2026-10-25-ui-restyle-design.md`: §4 (panel card, popups), §5 (theme), §7 (Thai fit).

The conventions follow `docs/superpowers/plans/2026-10-25-m2d-panels.md`. Its Rulings P12, P13, P14, P20 and P21 still hold: the popup queue, content passed in, gating by `validate`, the theme variations, and code-built panels using the `%Name` rule.

## Section and popup building blocks (used by every UI task)

These come from Task 3. Later tasks use them by name.

- `class_name PanelSection extends VBoxContainer`, in `src/ui/panels/panel_section.gd`:
  - `var panel: PanelBase`
  - `func build_key(view: GameState, t: TuningDef, content: ContentDB) -> Array`: virtual. The data shown; a change rebuilds the rows.
  - `func rebuild(view: GameState, t: TuningDef, content: ContentDB) -> void`: virtual. Adds the rows; the old children are already gone.
  - `func update(view: GameState, t: TuningDef, content: ContentDB) -> void`: virtual. Runs on every refresh, after the rebuild and the gating.
  - `func track(button: BaseButton, make: Callable) -> void`: `make` returns a `Command`, or `null` to disable with no tooltip. The button is gated now and on every refresh.
  - `func regate() -> void`
  - `func submit(cmd: Command) -> bool`
  - `func rebuild_now() -> void`: forces a rebuild now, for local UI toggles.
  - `func add_unique(parent: Node, node: Node, node_name: String) -> void`: a `%Name` child owned by the section.
  - `static func name_label(text: String, variation: StringName = &"") -> Label`: ellipsis, expands.
  - `static func wrap_label(text: String, variation: StringName = &"") -> Label`: word wrap, expands.
  - `static func row_panel(node_name: String) -> PanelContainer`: `RowPanel` holding a `VBoxContainer` named `Col`; use `row.get_node("Col")`.
  - `static func line() -> HBoxContainer`: separation 8.
  - `static func button(text: String, primary: bool = false) -> Button`
- `PanelBase` additions:
  - `add_section(section: PanelSection) -> void`
  - `sections() -> Array[PanelSection]`
  - `refresh_now() -> void`
  - `static gate_button(button: BaseButton, cmd: Command) -> void`
- `UiFormat.percent_bp(bp: int) -> String`: 100 → `"1%"`, 800 → `"8%"`, 1250 → `"12.5%"`, 2000 → `"20%"`.
- `UiFormat.level_key(level: int) -> StringName`: the `ui.level.*` key for a `Staff.Level` value.
- Tests use `SectionHarness`, in `tests/helpers/section_harness.gd`:

		if sec.get_script() == script:
			return sec
	var made: PanelSection = script.new() as PanelSection
	panel.add_section(made)
	return made
