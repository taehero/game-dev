# M2d-restyle: Clean Modern Tycoon UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the dark 1-Bit look with direction C. The office uses a colourful pixel-art mix: Kenney Modern City, Indoors, RPG Urban and Emotes, plus our own computer sprites. On top sits a flat, rounded UI: resource pills, a speed control, a project card, a floating dock, centred panels and a popup base. All of it is EN/TH and fits 640×360.

**Architecture:** `OfficeArt` stays the only file that knows sheets and cells. It now has several atlas sources, and art refs are `Vector3i(sheet, column, row)`. Colours live in `UiPalette`. `ThemeBuilder` builds the theme from those tokens, and `tools/gen_theme.gd` writes it to `main_theme.tres`. New HUD widgets follow the M2d rules: they read state only through `StateQueries`, re-read `GameRunner.session` on every `EventBus` event, and act only through `GameRunner`. `StatusBar` and `TabBarShell` are deleted in Task 11, once their replacements exist.

**Tech Stack:** Godot 4.7.2, GDScript (static typing), GUT 9.x, Kenney CC0 packs, Noto Sans Thai (OFL 1.1).

**Spec:** `docs/superpowers/specs/2026-10-25-ui-restyle-design.md` (binding). This spec replaces the visuals of M2 spec §11.1–11.3 (`docs/superpowers/specs/2026-10-24-m2-playable-garage-design.md`); the behaviour and data rules there still apply. Structure and conventions follow `docs/superpowers/plans/2026-10-24-m2d-office-scene.md`, whose Rulings 1–7, 9 (colours), 10, 11 and 12 still hold. Ruling 8 is superseded.

## Global Constraints

- Godot 4.7.2 at `/Users/chanapols/homebrew/bin/godot`. The project path has a leading space: always quote `"/Users/chanapols/Projects/ game-dev"`.

- Our sprites show fictional machines only: no real computer shapes, logos or brand colours.
- Display stays as M2d Ruling 1: logical 640×360, `canvas_items`, integer scale, Nearest by default, office node at scale 2. Pixel textures import lossless with no mipmaps. That rule covers every PNG under `assets/art/`, the icons included.

The TileSet holds the three tile sheets (CITY, INDOOR, STUDIO), with **source id equal to the `Sheet` value**. URBAN and EMOTES are used only through `atlas()`. Each sheet has its own separation; all margins are 0. *Cost if wrong:* one file (`office_art.gd`) and its tests.

3. **Own tiles: wood floor, carpet floor, wall top.** Indoors has no floor tiles, and Modern City has nothing that reads as wood or carpet. The spec allows our own tiles ("if no pack tile fits"). The garage keeps the CITY pavers. Side walls and the bottom row use our wall-top tile, because no pack tile shows a wall from above. *Cost if wrong:* a few pixels in the generator.
4. **Room geometry is unchanged.** `size_tiles`, `is_floor`, `cell_to_local`, `pixel_size`, the desk cells (M2d Ruling 3) and the Floor cell counts (10×5, 16×6) stay as they are. New art goes on new layers: `Ground` (grass ring, `GROUND_MARGIN = Vector2i(5, 3)` tiles outside the room) and `Decor` (props). The `WallBacking` / `FloorBacking` ColorRects are removed, because the new tiles are opaque.
5. **Sprite offsets live on child nodes**, so the scene-position tests keep their meaning:
   - `DeskSprite.position == cell_to_local(desk)`. The desk is two tiles wide and centred: `DeskLeft` at x −8, `DeskRight` at x +8. `Computer` is at `(0, -9)`.
   - `StaffSprite.position == cell_to_local(desk + (0,1))`. `Body` (back view) is at `(0, -7)`. `Chair` is drawn after `Body` at `(0, 4)`, using INDOOR (1,2) with its top 6 rows clipped, so the chair back covers the legs.
   - All values in this ruling are starting values: Task 12 may tune them by up to ±3 px and records the final ones.
6. **Bubble = emote icon + "+N type" pill**, both children of one `Bubble` node, so the cap of 24 still counts bubbles. The office is at scale 2 with Nearest filtering, so the pill counter-scales: `Pill.scale = Vector2.ONE / global_scale`, set when the bubble enters the tree. That makes its global scale 1, so its text renders crisp at logical size. `amount` comes from the `points_gained` payload. Colours stay M2d Ruling 9 (`UiPalette.POINT_COLORS`). The mockup's swapped design/art colours are not used (spec §3, §5).
7. **Theme is generated.** `ThemeBuilder.build()` reads `UiPalette`. `tools/gen_theme.gd` saves the result to `main_theme.tres`, and a test checks that the committed file matches the builder. Base `Label`/`Button`/`PanelContainer` keep content margins 6/1 (left-right/top-bottom) until the old bars are gone (`test_long_title_is_clipped` needs a 22 px StatusBar). The new looks live only in type variations. `LabelSmall` and `ButtonSmall` stay.
8. **Extra type variations.** Spec §5 lists seven text variations. The UI also needs panel variations: `PillPanel`, `CardPanel`, `TilePanel`, `DockPanel`, `TrackPanel`, `IconCircle`, plus `BubbleText`. They count as part of "one Theme resource".
9. **Pills show icon + value only** (spec §4: "icon in a coloured circle + bold number"). The `tooltip_text` names the value (`ui.pill.*`). The mockup's "แฟน"/"กระแส" labels are dropped. Game Icons has no coin glyph, so the money badge shows the text `tr("ui.pill.currency")` ("$").
10. **Measured widths** (Noto Sans Thai, measured by the planner; line heights: 10 px → 16, 12 px → 19, 14 px → 22). Fixed widths:
    - Pills (logical px): date 148, money 108, fans 104, hype 76.

    - Dock: 500×30 at x 70.
    
    The worst-case texts measured: "Year 1989, Week 52" 110, "-1,234,567" 69, "9,999" 37, "Equipment" 62, "No game in development" 143. If a fit test still fails, widen only that element by up to 8 px. Keep the top bar's pills ending before x 514, and report the change.

12. **Number formatting:** pills use `UiFormat.thousands()` (`1,234,567`, `-1,234,567`). Tiles show plain ints (`9999`).
13. **Topic and genre names:** `StateQueries.project_status` adds `topic_id` and `genre_id`. `ProjectCard.configure(name_keys: Dictionary[StringName, StringName])` maps id → `name_key`. Only `Main._content_names()` builds that map from `ContentDB.active()`, which extends M2d Ruling 5.
14. **Texture filter:** the roots of the UI scenes set `texture_filter = TEXTURE_FILTER_LINEAR`, so the 50 px icons scale down smoothly. These roots are `TopBar`, `ProjectCard`, `Dock`, `PanelHost` and `PopupCard`. `Main` and `OfficeSlot` keep the default, so the office stays Nearest.
15. **Icons:** the Game Icons *White 1x* PNGs (50×50) are copied individually from `PNG/White/1x/`, not from the sprite sheet, so no XML atlas needs parsing. They live in `assets/art/kenney_game_icons/` and fall under the asset tests.

17. **Speed control sync:** `SpeedControl.sync(GameRunner.session.speed)` runs on every TopBar refresh event and after a press. A speed change made from the debug HUD shows on the next event.
18. **Debug HUD:** every non-button Control under `DebugHud` gets `MOUSE_FILTER_IGNORE`. `Box` moves to the right side (offsets 330, 40 to 634, 264), so it does not cover the pills or the card. The node path `DebugLayer/DebugHud/Box/DateLabel` is unchanged.
19. **Fit tests check three things:**
    - natural text width ≤ rect width (`UiFit.text_fits`), because a clipped Label's minimum size is 0;
    - every rect is inside 640×360;
    - TopBar, ProjectCard and Dock do not overlap.
    
    The worst case is money 1,234,567 and −1,234,567, fans 1,234,567, hype 9,999, points and bugs 9999, stage 3/3 99%, and weeks 519 and 520 (520 per the spec; 519 gives the widest date, week 52).
