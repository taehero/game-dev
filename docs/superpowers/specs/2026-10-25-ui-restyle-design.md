# UI Restyle "Clean Modern Tycoon" — Design

Status: approved direction C (2026-10-25). Replaces the visual parts of M2 spec §11.1–11.3. Runs as plan **M2d-restyle**, before M2d-panels, so every later panel, popup and mini-game uses this style from the start.

Reference mockup: direction C (`ui-dir-c.png`, 1280×720). Mockup sources were throwaway; this document is the authority.

## 1. Goals

- The game reads as a colourful, modern studio tycoon instead of a dark debug tool.
- The office scene stays pixel art, top-down, integer-scaled. The UI on top is flat, rounded and smooth.
- Numbers that matter (money, fans, hype, points) are big and readable in EN and TH.
- Everything is built from free CC0 assets plus a few sprites we draw (§11.4 of the M2 spec).

Non-goals: era-specific skins, animation polish beyond simple tweens, sound (separate later task).

## 2. Rendering

- Keep the display rules: logical viewport 640×360, `canvas_items` stretch, `integer` scale, Nearest filter for textures.
- With `canvas_items`, Controls are laid out in 640×360 units but drawn at window resolution, so rounded corners, shadows and Thai text stay smooth. Pixel sprites stay crisp because their textures use Nearest.
- The office scene keeps its scale 2 node (art pixel = 4 screen px at 1280×720).

## 3. Office art (replaces the Kenney 1-Bit Pack)

| Use | Source | Licence |
|---|---|---|
| Walls, windows, doors, floors, outdoor props | Kenney Roguelike Modern City | CC0 |
| Desks, chairs, plants, shelves, rugs | Kenney Roguelike Indoors (16 px, 1 px spacing) | CC0 |
| People (modern clothes, 4 directions) | Kenney RPG Urban Pack | CC0 |
| Work bubbles (idea, music, star, bug, money) | Kenney Emotes Pack (pixel) | CC0 |
| Desk computers, 3 tiers | Our own 16 px sprites, generated by a script in `tools/` and committed as `assets/art/studio/computers.png` | own work |
| Indoor floor variants (wood, carpet) if no pack tile fits | Our own 16 px tiles in the same sheet | own work |

- Each pack keeps its `License.txt` next to its sheet and gets a row in `assets/CREDITS.md`. The 1-Bit Pack is removed from the repo and from CREDITS.
- Our sprites must depict fictional machines (no real computer shapes or logos).
- Seated staff: the Urban pack has no sitting pose. Staff use the back-view frame, placed one tile south of the desk, with a chair-back overlay drawn on top of the legs. Working staff bob as today.
- `OfficeArt` becomes the single place that knows sheets and cells, now with several atlas sources (per-sheet margin and separation). Scene code keeps asking `OfficeArt` for cells by name.
- Bubbles: the emote icon pops above the staff member; the coloured "+N type" text pill from the mockup is part of the bubble. Colours stay as M2d Ruling 9 (design green, tech blue, art orange, audio purple, bug red).

## 4. UI layout (640×360 logical)

| Element | Position | Content |
|---|---|---|
| Resource pills | top-left, row, 6 px margin | date · money · fans · hype. (The monthly money delta from the mockup is added in M2b, which owns monthly finance.) Each pill: icon in a coloured circle + bold number. |
| Speed control | top-right | segmented ⏸ 1x 2x 4x, active segment orange, dark track |
| Project card | left, under the pills, ~190 px wide | title (bold) + topic · genre, 3-segment stage bar (done green, current orange with progress, future grey), "stage N/M · progress %", tiles: design, tech, art, audio, bugs (number large, label small, tinted background) |
| Dock | bottom centre, floating, dark rounded | 5 tabs: Project, Team, Equipment, Finance, Market. Icon + label; active tab orange pill. |
| Panels | centred card above the dock | white rounded card, title row, content; opened by the dock (PanelHost API unchanged: `set_panel`, `show_tab`, `hide_panel`) |
| Popups | centred card, dim backdrop | used by review popup, production events, mini-games (M2d-panels) |

- The bottom status bar and the flat tab bar are removed. Their data moves to the pills and the project card.
- The project card hides when there is no active project and shows a small "no game in development" chip instead.
- The debug HUD stays behind F3 and does not block input (`mouse_filter` ignore).

## 5. Theme

One `Theme` resource (`src/ui/theme/main_theme.tres`), all `StyleBoxFlat`:

- Tokens (defined once in `src/ui/theme/ui_palette.gd` as constants, used by the theme builder and by code that tints tiles):
  - surface `#FFFFFF`, surface-alt `#F3F4F6`, text `#1F2937`, text-muted `#6B7280`, dock `#1F2937`, accent `#F97316` (orange), money `#22A06B`, fans `#E0457B`, hype `#F2A93B`, date `#4B5563`, success `#3BB27F`, warning `#F2B53B`, danger `#E5484D`; point colours as Ruling 9.
- Radii: pills 12, cards 10, tiles 8, dock 14. Shadow: 0,2 offset, size 4, alpha 0.18.
- Fonts: Noto Sans Thai (existing variable font). Body weight 400 size 12; numbers and titles weight 700 via a second `FontVariation` (`wght` 700), sizes 14–16. Small labels 10.
- Type variations: `PillLabel`, `NumberLarge`, `CardTitle`, `TileNumber`, `TileLabel`, `DockButton`, `SegmentButton`.
- Icons: Kenney Game Icons (CC0), white glyphs tinted per use, 16×16 logical.

## 6. Data the UI needs (StateQueries, pure)

- `resource_view(state, t) -> Dictionary`: `date_text`, `money`, `fans` (`Company.fan_count`), `hype` (active project hype or 0).
- `project_status(...)` already returns title, stage, stage_count, progress, points, bugs, hype; add `topic_id`, `genre_id` for the subtitle.
- No UI code reads entities directly (hard rule 3).

## 7. Text and locale

- New keys for pill tooltips, dock labels (existing `ui.tab.*` reused), "no game in development", stage text. All EN + TH, added in one task.
- Thai must fit: every pill and tile clips with ellipsis at its fixed width; a test renders the worst case (7-digit money, 4-digit points, week 520) in TH and EN and checks no element exceeds its rect and nothing exceeds 640 px.

## 8. Tests

- Theme test: required type variations exist; fonts have Thai and Latin glyphs.
- Layout tests: pills, card, dock and speed control positions inside 640×360; card hides with no project; dock tab toggling drives PanelHost.
- Art tests: every `OfficeArt` cell lies inside its sheet; every sheet's `License.txt` contains CC0 (except our own sheet, which has a `README` stating own work); no 1-Bit Pack file remains.
- Existing scene tests (seats, bubbles cap, game_loaded rebuild, unshown staff) keep passing after the art swap.
- Manual check on macOS: screenshot at 1280×720 and 1920×1080, EN and TH.

## 9. Spec changes

- M2 spec §11.1: office art is the pack mix in §3 here.
- M2 spec §11.2: pack list replaced by §3 here; own sprites allowed.
- M2 spec §11.3: bottom status bar replaced by pills + project card + dock (§4 here).
- M2d plan Ruling 8 (date/money in the status bar) is superseded.
